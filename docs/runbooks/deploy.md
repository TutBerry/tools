# Развёртывание и откат TutBerry

Стенд задаётся переменной STAND_URL среды staging. Каталог на стенде — ~/tutberry. Доступ к Docker и SSH предоставляется оператору. Секреты не коммитируются.

## Развёртывание

1. Найти успешный запуск CI основной ветки, метку sha-… и digest опубликованного образа.
2. В Actions → Deploy staging → Run workflow выбрать main, указать метку, оставить migrate=true.
3. Дождаться проверки /health и точного совпадения /version с меткой.
4. Проверить поиск инструментов через GET /api/listings с допустимыми start_date и end_date.

API слушает loopback стенда; для проверки из Actions нужен согласованный доступ через защищённый прокси или SSH-туннель. Не открывать административные порты.

## Откат

Найти предыдущую успешную метку в журнале. Убедиться, что предыдущий код совместим с текущей схемой БД. Запустить тот же Deploy staging с предыдущей меткой и migrate=false. Проверить /health, /version и поиск.

Аварийный вариант на стенде: из ~/tutberry указать предыдущую метку через IMAGE_TAG и выполнить docker compose -f compose.prod.yaml pull api worker, затем docker compose -f compose.prod.yaml up -d --wait api worker. Использовать конфигурацию соответствующего релиза. Ручное переопределение не обновляет .env и журнал автоматически; оператор обязан согласовать состояние и записать результат.

## Если миграции уже применены

Проверить docker compose -f compose.prod.yaml run --rm --no-deps api python manage.py showmigrations. Предпочтительно завершить развёртывание новой версии. Перед обратной миграцией проверить обратимость, совместимость и резервную копию. Не откатывать схему автоматически: необратимые изменения требуют отдельного плана восстановления.

## Журнал

Сводка Actions и ~/tutberry/docs/runbooks/deployment-log.md: UTC, метка, оператор, результат, ссылка на запуск. Журнал не коммитируется в main. При недоступности SSH запись на стенде невозможна, использовать сводку Actions.

## Подтверждение

Изолированный rollback smoke прошёл: https://github.com/TutBerry/tools/actions/runs/45458265035 . Использованы два образа одинакового кода с разными версиями. Реальное развёртывание, откат после изменения схемы и простой на стенде ещё не проверены.
