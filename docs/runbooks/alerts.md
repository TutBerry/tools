# Реакция на оповещения

| Оповещение | Симптом | Первое действие |
|---|---|---|
| HighErrorRate | 5xx > 0,5% | Проверить /ready, последние изменения и журнал API; при необходимости откатить |
| SlowListingSearch | p95 > 300 мс | Проверить Valkey, запросы PostgreSQL и план поиска |
| SlowBooking | p95 > 500 мс | Проверить блокировки PostgreSQL и трассировку записи |
| ServiceUnreachable | Prometheus не получает метрики | Проверить доступность API и сеть |
| OutboxBacklog | Более 100 неопубликованных событий | Проверить worker, RabbitMQ и журнал relay |
| OutboxDelayed | Старейшее событие ждёт более 60 с | Восстановить worker или брокер, проверить уменьшение очереди |
| ServiceNotReady | Существенная зависимость недоступна | Восстановить PostgreSQL, проверить /ready |

Сначала восстановить обслуживание, затем исследовать причину. Зафиксировать UTC, версию, влияние и время восстановления. Не удалять очередь или том БД. Правила адаптированы к текущему Outbox; это не полный набор предметных сигналов из методички.
