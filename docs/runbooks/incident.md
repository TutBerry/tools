# Инцидент

1. Зафиксировать время, версию, симптомы и влияние по метрикам.
2. Восстановить доступность: проверить /ready, зависимости, очередь и журнал; при необходимости согласовать откат.
3. Сопоставить трассировки и журналы, определить причину.
4. Записать хронологию, число ошибок, длительность, действия, ответственных и сроки. Не подменять фактические измерения примером из методички.
