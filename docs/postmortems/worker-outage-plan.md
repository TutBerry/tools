# Учебный инцидент — остановка worker

Статус: план, не результат проведённого упражнения.

На изолированном стенде GitHub Actions запустить Compose с профилем observability. Создать тестовые объявления и пользователей. Подать запросы поиска и бронирования с непересекающимися датами. Остановить worker, не останавливая API или PostgreSQL. Проверить накопление Outbox и срабатывание OutboxDelayed. Восстановить worker и проверить публикацию накопленных событий и исчезновение сигнала.

Записать фактическое время UTC начала, обнаружения, восстановления и исчезновения сигнала, число успешных и ошибочных запросов, размер очереди, ссылки на журналы и метрики. После восстановления исследовать причину по журналам и трассировке.

Отклонение: API отмены бронирования отсутствует, поэтому для нагрузки нужны отдельные даты или объявления. Автоматический сценарий не заменяет командное упражнение вслепую. Фактических измерений пока нет.
