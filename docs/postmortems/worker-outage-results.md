# Результаты учебного инцидента

27.11.2026, GitHub Actions, Lab 7 worker outage №3, коммит d29ceb7. Запуск успешен, общая длительность 5 мин 57 с (по интерфейсу Actions).

Автоматический сценарий проверил создание бронирования при остановленном worker, срабатывание OutboxDelayed, восстановление worker, опустошение Outbox и исчезновение оповещения. Причина отказа — намеренная остановка worker на изолированном стенде.

Точные UTC-отметки, MTTD и MTTR необходимо извлечь из incident-evidence/incident.log. Общая длительность workflow не является MTTR. Данные о количестве ошибок и доставке писем отдельно не подтверждены. Командное упражнение вслепую не проводилось.

Дальнейшие действия: проверить доставку уведомлений, сохранить журнал и уточнить измерения; ответственные и сроки требуют согласования команды.
