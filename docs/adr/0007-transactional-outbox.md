# Transactional Outbox

Событие записывается в PostgreSQL в транзакции бронирования. Worker выбирает неопубликованные записи с блокировкой SKIP LOCKED, публикует с подтверждением брокера и отмечает время публикации. При сбое до отметки возможна повторная доставка, поэтому сохраняется дедупликация. Измерение выигрыша задержки и тест реального отказа ещё необходимы.
