# Лабораторная работа 7 — модуль 14

Цель — повысить наблюдаемость, надёжность и защищённость платформы аренды инструментов TutBerry.

## Результаты
- Добавлен профиль observability: Prometheus, Grafana, Jaeger; HTTP-метрики и трассировка.
- Реализованы Outbox, проверка готовности, аудит создания брони и ограничение частоты.
- Описаны SLO, семь оповещений, инструкции реагирования и аудит Д-15.
- CI №185 (e8c28b2) успешен; проверка ролей PostgreSQL №9 успешна; учебный инцидент №3 (d29ceb7) успешен, длительность workflow 5 мин 57 с.
